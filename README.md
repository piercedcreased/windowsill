# Windowsill

Rain on a window, calm sounds, live weather and quiet games, for Windows.

**[Download WindowsillSetup.exe](https://github.com/piercedcreased/windowsill/releases/latest/download/WindowsillSetup.exe)**, run it, and Windowsill installs into its own folder with a Start menu shortcut. No admin rights needed.

Windowsill lets you know when a new version is ready and updates itself.

If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. The installer isn't code-signed.
